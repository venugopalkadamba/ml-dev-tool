# A No-code Bias-aware Machine Learning Pipeline Generation Platform for Algorithmic Fairness Research

A lightweight, reproducible workbench for fairness-focused ML experiments. It combines a Streamlit UI with a transparent Python core to generate datasets (synthetic or benchmark), inject controlled biases, preprocess data, train models, and evaluate performance and fairness metrics. Ideal for rapid ideation, classroom demos, and artifact-ready experiments.

## Features
- **Data**: Synthetic dataset generation and loading of popular benchmarks (e.g., Adult, Iris).
- **Bias Injection**: Representation, Measurement, Sampling, Label biases (training-only).
- **Preprocessing**: Missing value imputation, skewness treatment, binning, feature encoding.
- **Modeling**: Any scikit-learn estimator, weighted ensembles, stacking; LightGBM/CatBoost support.
- **Evaluation**: Standard metrics (accuracy/F1/ROC-AUC/PR-AUC/log loss) + fairness metrics.
- **Comparison**: Side-by-side comparisons of multiple pipelines and visual reports.

## Architecture
The tool follows a three-layer design: Tool UI (Streamlit), Core Engine (Python pipeline & evaluation), and ML Backend (estimators).

## Quick Start

### Python Version
- Recommended: **Python 3.10–3.11**

### Setup
```bash
# Clone
git clone <your-fork-or-repo-url>
cd ml-dev-tool

# Create & activate a virtual environment (choose one)
# Windows (PowerShell)
python -m venv .venv
. .venv/Scripts/Activate.ps1
# macOS/Linux (bash/zsh)
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install --upgrade pip
pip install -r requirements.txt
```

### Run the App (Streamlit)
```bash
# From the project root
streamlit run app.py
```
If Graphviz is required for diagram rendering on Windows, ensure it is installed and on PATH.

## Usage

### 1) Dataset Collection / Preparation
- Load benchmark datasets or generate synthetic data with controllable distributions and protected-attribute ratios.
- Optionally inject biases (Representation, Measurement, Sampling, Label). Bias is applied only during training.

### 2) Data Pre-Processing and Modeling
- Apply imputation (mean/median/mode), skewness treatment (log/sqrt/Box–Cox/exp), binning (quantile/custom), and feature encoding (label/one-hot).
- Train any scikit-learn–compatible model, create weighted ensembles, or build stacking meta-learners. LightGBM and CatBoost are supported.

### 3) Model Evaluation
- Compute accuracy, precision/recall/F1, ROC/PR curves and AUCs, log loss, and fairness metrics (e.g., demographic parity ratio).
- Visualize results in the UI and export artifacts for reporting.

### 4) Multiple Pipeline Comparison
- Build multiple pipelines and compare them side-by-side across metrics and plots.
